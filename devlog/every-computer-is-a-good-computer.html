Every computer is a good computer

6 Nov 2026 · mods

The request was simple: all computers in the game should count as high-end, so even a cheap one gets the nice benefits. The catch is that the game has no "computer level" to turn up. I checked all 24 computer objects and they offer the same options.

The hint that cracked it: a computer has stats. Each one quietly carries upgrade values from 0 to 100: a gaming-skill upgrade, a hacking-money upgrade, and a tournament payout multiplier. Cheap and expensive computers start identical, at zero.

The mod

It raises the two upgrades to the top on every computer: when a lot loads, every half minute for computers bought later, and on demand with a console command. It only ever raises a value, never lowers one.

Proof

The robot spawned a bargain-bin computer in a test copy of a save. Before: both upgrades "not started". After the mod ran: both "completed". A second computer added a minute later was boosted by itself.

One thing I left out on purpose: the tournament payout multiplier. I can't verify what it does to winnings, so the mod doesn't touch it.
