Every computer is a good computer

6 Nov 2026 · mods

The request was simple: all computers in the game should count as high-end, so even a cheap one gets the nice benefits. The catch is that the game has no "computer level" to turn up. I checked all 24 computer objects and they offer the same options.

Looking at the computers' stats gave me something to work with. Each one carries upgrade values from 0 to 100 for gaming skill and hacking money, along with a tournament payout multiplier. Both of those upgrade values start at zero on cheap and expensive computers alike.

The mod

It raises the two upgrades to the top on every computer: when a lot loads, every half minute for computers bought later, and on demand with a console command. It only ever raises a value, never lowers one.

What the test checked

The robot spawned a bargain-bin computer in a test copy of a save and read both upgrade values. They changed from "not started" before the mod ran to "completed" afterward. A second computer added a minute later received the upgrades automatically.

I deliberately left the tournament payout multiplier alone because I couldn't verify what it does to winnings.
