Two mods that quietly did nothing

6 Nov 2026 · fixes

Once the test robot existed, we pointed it at the small mods too and found two that loaded without errors but did absolutely nothing. Those failures were harder to spot than a crash, so they could easily have gone unnoticed for weeks.

Surprise Gifts

The log said "gift candidates: 0" every single day. The mod hunted for gift items by searching object names, but the game's data doesn't carry readable names for them, so the search matched nothing. The fix was a curated list of known items, checked against what the game will actually accept, and a command that hands one over on demand so a test can trigger it.

Toddler TV

The game already has a toddler-only "Watch" option on every TV, but it requires the TV to be switched on. The first version of the mod changed the wrong rule and had no effect. The fix removes that condition, so when a toddler starts watching an off TV, it switches itself on to the kids' channel and shuts off a few minutes later.

There's no toddler animation for pressing the remote, so the TV comes on by itself rather than showing the toddler switch it on, and toddlers still can't pick channels.

How we know

Both mods were checked in the real game on a test copy of a save, using the game's own checks and actual interactions. The captures above show the gift notification and a toddler watching the television.
