MoveAnywhere

Move a household into any lot, parks included, straight from Manage Worlds. The lot arrives as a real home:

  • lot type reads Residential and stays editable
  • build mode uses the household's own funds, with no stray business wallet
  • the normal build catalog, not "Park Items"
  • no surprise "Building Lot" screen

Checked end to end by an automated test that moves in, opens build mode, saves and reloads. Last run: 6 Nov 2026, version 13.1, 28 of 28 checks passed. Also checked: moving in through the in-game move menu, households with almost no money, saves that already had a household in a park, and evicting a household (evicted households are rehoused when a suitable empty home is available). Download coming once it has been played with for a while.
